# 🤖 Multi-Modal AI Aggregator & Monetized Telegram Bot

Полнофункциональный и коммерческий Telegram-бот на базе **Aiogram 3**, объединяющий передовые языковые модели, генерацию визуальных концептов, мультимодальный анализ изображений и встроенную монетизацию через **CryptoBot**.

---

## 🚀 Основные возможности

- **💬 Текстовый ИИ-ассистент:** Интеллектуальные ответы на любые вопросы с поддержкой контекста и красивым форматированием (Markdown).
- **🎨 Генерация визуальных концептов:** Создание детальных описаний и концептов изображений по текстовому запросу.
- **👁️ Vision-анализ:** Возможность отправлять фотографии с вопросами или описанием для глубокого анализа нейросетью.
- **⚡ Неблокирующий интерфейс:** Асинхронная архитектура с использованием `asyncio.to_thread` обеспечивает высокую отзывчивость интерфейса и стабильную работу анимации «печатает...» в Telegram.
- **💳 Встроенная монетизация (Freemium):** Ограничение бесплатных генераций изображений с автоматической выдачей счетов на оплату подписки через **CryptoBot** (поддержка USDT, TON, банковских карт и др.).

---

## 🛠 Технологический стек

- **Язык:** Python 3.10+
- **Фреймворк для Telegram:** Aiogram 3
- **AI API:** OpenRouter / OpenAI (DeepSeek, Gemini и др.)
- **Платежный шлюз:** AioCryptoPay (`aiocryptopay`)
- **Асинхронность:** `asyncio`

---

## 📂 Структура проекта

```text
├── bot.py                # Главный файл бота (обработчики, стейт-машина, роутинг)
├── route.py              # Роутер пользовательских запросов (текст/изображения)
├── image_generator.py    # Модуль генерации визуальных концептов
├── vision_analyzer.py    # Модуль анализа изображений (Vision API)

├── requirements.txt      # Зависимости проекта
└── .env                  # Секретные ключи (не попадает в репозиторий)
```
